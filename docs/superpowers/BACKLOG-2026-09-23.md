# Backlog, 2026-09-23

Reported by the designer in one list. Grouped by the code each group touches, so that one group
reads one area of the tree. The numbers are the designer's own.

**Status:** open. Mark each item `done` with its commit when it lands.

## A. Serif presets (panel and preset model)

- **done** — **2 — The built-in presets are not in the preset browser.** Egyptian, Clarendon, Didone,
  Old style and Wedge must show in the browser. The designer must be able to edit them, and to
  update them from the canvas.
- **done** — **2a — Right-click on the preset dropdown resets to Egyptian.** It must reset the current
  preset, if it is a built-in, to its shipped values.
- **done** — **2b — Switching the terminal tab resets the adjustments and forces Egyptian.** Every canvas
  adjustment must survive a change of terminal type and back.
- **done** — **2c — A preset changed on the canvas and not updated (arrow up) shows no mark.** Mark it in
  the closed dropdown, for example with text at 60% opacity.

## B. Ribs

- **done** — **4 — Tied ribs must show and keep their real value.** Ribs of 50 and 60, tied on the 60 rib,
  show 60 and 60. When the tie is turned off, they stay 60 and 60.
- **5 — A new skeleton point in single-sided mode gets a rib width of 0.** It must get the width
  of the stroke at the placement point, rounded to units, as in double-sided mode.

## C. Gizmos

- **3 — Gizmos block a double-click on path and skeleton contours.** A gizmo with no reset must
  pass the double-click through, so that it selects the segment.
- **6a — Alt-drag on an on-curve Tunni gizmo (orange diamond)** must lock the drag to its axis,
  with no way to change the axis, as the X drag does.
- **6b — On-curve Tunni gizmos fade in and out like the curvature gizmos**, with longer delays
  for both. Put the controls in the Tunni debug panel.
